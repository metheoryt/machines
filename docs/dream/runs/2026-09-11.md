## Conventions this run invented, so the next run reproduces the same ids

`dream.sh index` emits `##` rows only, and several findings have no heading at all. Until
the skill settles this (filed as `f7082e6e`), this run used:

- whole-file finding → anchor **`(whole file)`**
- per-branch finding → anchor **`(branch: <name>)`**
- fleet-wide finding about the shared set → anchor **`(fleet: shared stores vs origin/main)`**
- a finding under a `###` → the **enclosing `##`**, with the `###` named in the `why`

And where one `(target, anchor, action)` triple carried several distinct findings, they
were merged into **one item with numbered `### Part N` sub-decisions**, each with its own
evidence, bytes and replacement. That is a workaround for an id collision, not a design —
see `f7082e6e`.
